# Classic Taskbar Groups privacy policy

_Last updated: November 23, 2026_

Classic Taskbar Groups is published by Deck-Of-Jacks.

## Summary

Classic Taskbar Groups collects no personal data, and it does not send any data off your PC.

## Details

- **No data collection.** The app has no telemetry, analytics, crash reporting, accounts, or advertising, and it does not check for updates.
- **No network connections of its own.** The app does not connect to the internet or to any server. If you add a web link to a folder and open it, your default web browser opens that address under that site's own privacy policy. The app never opens a web page on its own.
- **Folders and items stay on your PC.** Your folders, items, custom icons and settings are saved in a settings folder in your Windows user profile. Nothing is uploaded. Uninstalling the packaged app removes its data.
- **Export and import.** Export writes one file you choose, containing your folders, items, icons and settings. Import reads a file you choose. Those files stay wherever you saved them. Import does not turn on Start with Windows.
- **Start with Windows (optional, off until you opt in).** In the packaged app this uses a Windows startup task. In the unpackaged exe it uses a shortcut in your Windows Startup folder. Both stay on your PC.
- **Launching an item.** Choosing an item starts that app, file, folder or link on your PC. The app does not send anything about the item anywhere.
- **Hover-to-open (optional, off by default).** When you turn this on, the app uses read-only UI Automation on your PC to find the folder's taskbar button. That information is not saved or sent.
- **Other Classic apps.** Opening Classic Taskbar Groups from Classic Control starts it if it is installed, or opens its Microsoft Store page if it isn't.

## Changes to this policy

If this policy changes, the updated version is posted at this same address with a new "Last updated" date.
