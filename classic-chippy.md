# Classic Chippy privacy policy

_Last updated: November 16, 2026_

Classic Chippy is published by Deck-Of-Jacks.

## Summary

Classic Chippy collects no personal data. Nothing leaves your PC except the optional web searches you choose to open.

## Details

- **No data collection.** The app has no telemetry, analytics, crash reporting, accounts, or advertising, and it does not check for updates.
- **Searching happens on your PC.** Questions you type are matched against a list of Windows settings and answers built into the app. Nothing you type is sent anywhere.
- **Web searches you choose.** When you pick a web search or a Microsoft Learn search, your search text is opened in your default web browser. That website handles the search under its own privacy policy. The app never searches the web on its own.
- **Copied errors (optional, off by default).** When you turn on explaining copied errors, the app reads clipboard text in memory to see whether it looks like an error message. Clipboard text is never stored or sent.
- **Screenshot text (optional).** When you take a window screenshot, or paste or drop an image, and choose to read its text, the image is read with the text recognition built into Windows, on your PC. Screenshots and the text read from them are kept in memory only. They are never stored or sent.
- **Windows error tips (optional, off by default).** When you turn on error tips, the app reads recent System and Application errors from the Windows event logs on your PC to offer a tip. Event log entries are read in memory only. They are never stored or sent.
- **Quick fixes and commands.** Fixes open built-in Windows settings or Control Panel, or copy a command for you to run yourself. The app never runs commands. It runs as a standard user. The Open elevated PowerShell button only opens an empty PowerShell window through the normal Windows administrator prompt.
- **Other Classic apps.** Opening another Deck-Of-Jacks app starts it if it is installed, or opens its Microsoft Store page if it isn't.
- **Settings stay on your PC.** Your preferences, such as the hotkey, sounds, start with Windows, the tips you chose not to see again, and when the last tip was shown, are saved in a settings folder in your Windows user profile. They never include clipboard text, screenshots, recognized text, or event log contents. Nothing is uploaded. Uninstalling the packaged app removes its data.
