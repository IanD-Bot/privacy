# Classic Explorer privacy policy

_Last updated: November 23, 2026_

Classic Explorer is published by Deck-Of-Jacks.

## Summary

Classic Explorer collects no personal data, and it does not send any data off your PC.

## Details

- **No data collection.** The app has no telemetry, analytics, crash reporting service, accounts, or advertising.
- **No network connections of its own.** The app browses folders through Windows on your PC. When you open a network share, a server, OneDrive or another online location, Windows reaches it the same way File Explorer does. The app does not check for updates.
- **Icons, thumbnails, previews and search.** Icons and thumbnails come from Windows on your PC. The preview pane uses the preview handlers installed on your PC, as File Explorer does. Searches run on your PC, with Windows Search where the folder is indexed.
- **Tags.** Tags are stored in a database in the app's local data folder on your PC. Each tagged item also gets a small hidden stream with its tag names, so its tags can be restored after a move. Tags are never uploaded or shared.
- **Settings.** Views, panes, tabs to restore, the right-click menu layout and the hotkey are saved in the app's local data folder on your PC.
- **Export and import.** **Export setup...** saves your settings and tags, with the paths of the tagged items, to a file you choose. The app never uploads it. **Import setup...** only reads a file you choose.
- **Windows integration (off by default).** If you turn on **Open folders in Classic Explorer**, the app changes the default action for folders in your own user's registry settings, and turning it off puts the earlier settings back. The new-window hotkey and the commands in File Explorer's right-click menu work on your PC only.
