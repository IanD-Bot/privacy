# Petty Darn File support

_Last updated: November 18, 2026_

Petty Darn File is published by Deck-Of-Jacks.

## About this app

Petty Darn File is a Windows desktop app for everyday PDF jobs on your own PC. You can open, merge, and rearrange PDFs, add text, checkboxes, and fillable fields, type, draw, or upload a signature or initials, recognize text on scans, and fill copies from a CSV or Excel file — one combined PDF or one file per row.

## Requirements

Windows 10 version 2004 (build 19041) or later, 64-bit.

## Install and launch

Install the app from the Microsoft Store, then open it from the Start menu. Open a PDF with Open, or drop a file on the window.

## Settings

Saved signatures, initials, and merge templates stay only on this computer. A file is opened and saved only in the place you choose. Nothing is uploaded.

## Common questions

- **Does this app upload my files?** No. It does not connect to the internet or to any server. Text recognition, form detection, signatures, and data merge all run on your PC.
- **What does text recognition do?** It adds an invisible searchable layer and leaves the visible page unchanged. You can recognize this page, a page range, or the whole file.
- **How do I fill copies from a spreadsheet?** Open your PDF, then fill copies from a CSV or Excel file. Map columns to form fields or drag a column onto the page, preview the first rows, and write one combined PDF or one file per row named from a pattern.
- **Can I split, rotate, or merge pages?** Yes. Merge more PDFs into the same document, then use the thumbnail strip to reorder, rotate, delete, or split pages. You can also insert a PNG or JPEG as a new page.

## Reset and uninstall

Uninstall the app from Settings > Apps. Uninstalling removes the app. Files you already saved are left where you put them.
