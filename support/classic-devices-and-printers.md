# Classic Devices and Printers support

_Last updated: November 18, 2026_

Classic Devices and Printers is published by Deck-Of-Jacks.

## About this app

A classic Devices and Printers window for the printers, scanners, and Bluetooth devices Windows already knows about. Add a printer and Add a device open the built-in Windows wizards. The app does not scan the network or hunt for unpaired devices on its own.

## Requirements

Windows 10 version 2004 (build 19041) or later, 64-bit.

## Install and launch

Install the app from the Microsoft Store, then open it from the Start menu.

## Settings

A setting can hide virtual printers such as Microsoft Print to PDF, XPS, and Fax. That choice, and the last window size and position, are saved in a settings folder in your Windows user profile. Nothing is uploaded.

Light and dark mode follow Windows, including the title bar.

## Common questions

- **A printer or device is missing.** The list shows only what Windows already knows about. Use **Add a printer** or **Add a device** to open the built-in Windows wizards, or choose **Refresh**. The list also updates when Windows reports a change.
- **I can't set the default printer.** If Windows is managing your default printer, the app asks whether to open Windows printer settings. Turn off "Let Windows manage my default printer" there yourself. When you return to the app or choose Refresh, it re-checks the setting and can set the printer you chose. The app never changes that Windows management setting itself, and it does not ask for administrator permission for Set as default.
- **Bluetooth is empty.** If Bluetooth is off, the section says so and stays empty. Battery level is shown only when Windows exposes one.
- **Rename or remove asked for administrator permission.** A short-lived helper runs only when a local printer rename or removal needs it, and only after you approve the Windows prompt. Cancelling the prompt leaves everything unchanged.

## Reset and uninstall

Uninstall the app from Settings > Apps. Uninstalling the packaged app removes its data.
